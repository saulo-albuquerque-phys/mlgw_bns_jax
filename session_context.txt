## Key Architecture Facts

- mlgw_bns_jax model: MLP 5→82→95→30 (tanh), 11,847 params
  PCA: 30→6197 components (5046 amp + 1151 phase)
- jax_import_n_predict.py: 638 lines, standalone JAX predictor
- load_predict(path) → predict(params, frequencies_hz, total_mass, distance_mpc, inclination)
- Cubic spline tridiagonal solver via jax.lax.scan
- Float64 enforced

- JenpyROQ 0.0.1 from GitHub, patched for numpy 2.0
